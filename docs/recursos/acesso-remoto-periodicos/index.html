Tutorial: Acessando artigos de casa via SSH

Guia para rotear o tráfego do Google Chrome através da rede do Ifes estando em casa e acessar bases pagas (IEEE, CAPES, etc.).

Passo 1 Estabelecer o túnel SSH (SOCKS5)

No seu computador em casa, abra o Terminal (Linux/Mac) ou o Prompt de Comando/PowerShell (Windows) e execute o comando abaixo para redirecionar o tráfego dinâmico:

ssh -D 1080 usuario_ifes@ip_ou_host_do_pc_remoto

Digite a senha do usuário do computador do Ifes quando solicitado. Mantenha esta janela do terminal aberta enquanto estiver lendo os artigos.

Passo 2 Configurar o proxy no Google Chrome

  1. Instale uma extensão de gerenciamento de proxy no Chrome (ex.: Proxy SwitchyOmega ou FoxyProxy).
  2. Crie um novo perfil de proxy com as seguintes configurações:
    • Protocolo: SOCKS5
    • Servidor (Server): 127.0.0.1
    • Porta (Port): 1080
  3. Clique no ícone da extensão no canto superior do Chrome e ative o perfil recém-criado.

Passo 3 Teste e validação do acesso institucional

Para confirmar que a conexão está funcionando e que as bases de periódicos estão reconhecendo o IP do Ifes, faça o teste final:

Link de teste: acesse o artigo de teste no IEEE Xplore: https://ieeexplore.ieee.org/document/10716301
