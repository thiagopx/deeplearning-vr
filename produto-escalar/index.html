Álgebra linear para classificadores

Produto escalar

Um vetor é só uma lista ordenada de números — e cada número é uma característica (feature) do que ele representa. O produto escalar é a operação que compara dois vetores, e é o mecanismo por trás de toda pontuação linear, incluindo a fronteira de decisão.

→
x = (0.10, 0.90, 0.10, 0.90, 0.90, 0.90, 0.10, 0.90, 0.10)
Uma imagem 3×3 "achatada" linha a linha vira um vetor de 9 dimensões — um por pixel. Para visualizar, ficaremos em 2D daqui pra frente, mas tudo generaliza para qualquer número de dimensões.

Comprimento (norma) de um vetor

A norma mede o tamanho de um vetor, independente da direção:

‖x‖ = x12 + x22 + ⋯ + xd2

Vamos precisar disso para separar o tamanho de um vetor da sua direção.

Produto escalar

Dados dois vetores a e b, o produto escalar pode ser calculado de duas formas equivalentes:

a·b = a1b1 + a2b2 + ⋯ = ‖a‖ ‖b‖ cos θ

O lado esquerdo é fácil de calcular; o lado direito é o que torna o produto escalar interessante — ele liga uma operação puramente algébrica a uma geometria: o quanto a e b apontam na mesma direção, escalado pelo tamanho de cada um.

Projeção de um vetor sobre outro

O produto escalar também responde a uma pergunta geométrica: quanto de a está na direção de b? A "sombra" que a ponta de a projeta sobre a reta de b é a projeção. Seu comprimento (com sinal) é:

compba = a·b‖b‖

Positivo quando a sombra aponta no sentido de b (θ < 90°), negativo quando aponta no sentido oposto (θ > 90°), e zero quando a e b são perpendiculares — a não projeta sombra alguma sobre b.

Calculando à mão

Para os vetores a e b que você está arrastando no gráfico, resolva no papel e depois confira:

  1. Norma de a ‖a‖
  2. Norma de b ‖b‖
  3. Produto escalar (forma algébrica) a·b
  4. Cosseno do ângulo cos θ = (a·b) / (‖a‖‖b‖)
  5. Ângulo θ = arccos(cos θ)
  6. Projeção escalar de a sobre b compba = (a·b) / ‖b‖

Efeito do ângulo e da magnitude

O produto escalar mistura duas coisas diferentes. Percorrendo uma curva (mesma cor), o que muda é só o ângulo: a·b oscila como um cosseno — máximo quando a e b apontam para o mesmo lado (θ = 0°), zero quando são perpendiculares (θ = 90°), mínimo quando são opostos (θ = 180°). Comparando curvas de tons diferentes, o que muda é a magnitude de b: escalar b por um fator α apenas estica a curva na vertical — a forma não muda, só a amplitude. O ponto marcado é o par (a, b) que você está arrastando no gráfico.

Produto escalar como similaridade

Para medir só o alinhamento — sem a confusão do tamanho acima — normalizamos os dois vetores antes. Essa é a similaridade de cosseno:

sim(a,b) = a·b‖a‖‖b‖ = cos θ ∈ [-1, 1]

Para lembrar. O produto escalar liga álgebra a geometria: a soma dos produtos das coordenadas é igual a ‖a‖‖b‖cos θ. Dividindo pelas normas, isolamos só a direção — essa é a mesma métrica usada para comparar vetores de características entre imagens.
